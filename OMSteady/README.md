# omsteady

Steady-state solver for OpenModelica hand guided tearing (HGT) problems, the
Python part of phase 1 in `doc/HGT_interactive_fmu_phase1.md`.

- `FMUProblem(path)`: an interactive FMU generated by
  `omc --handGuidedTearing --interactiveFMU` (FMI 2.0 Model Exchange, needs FMPy).
  Iteration variable N is the FMU input aliased by `iter_N`, residual N is the
  output `res_N`, `iter_N_hold` and `res_N_hold` are the hold parameters, and the
  structure comes from `<ModelStructure><Outputs>`.
- `FunctionProblem(...)`: the same problem given by Python functions.
- `Solver(problem, ...).solve()`: holds (from the hold parameters and from
  `holdIterationVariables`/`holdResiduals`), count and structural checks, then a
  damped Newton method with residual scaling and bounds, optionally block by block.

```python
from omsteady import FMUProblem, Solver
p = FMUProblem("twoEqSteadyStateParaHold.fmu")
p.set("testHold1", True)       # hold T, drop LongEq
p.set("T", 330.0)
print(Solver(p).solve(), p.get(["x", "T"]))
```

Tests: `pip install -e .[test,fmu]`, then `pytest tests`.
